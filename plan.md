# SEO Optimization Plan for Fluxo Blog


## 3. Оптимізація контенту та структури (Поради на майбутнє)
- [ ] **Короткі URL-адреси (Slugs).**
  - Не змінювати старі URL, щоб не зламати індексацію!
  - Для нових статей використовувати короткі, ключові URL (наприклад: `/blog/study-workflow-applied-knowledge/` замість довгого речення).
- [ ] **Внутрішня перелінковка (Internal Linking).**
  - Додавати 2-3 контекстні посилання прямо в тексті абзаців на інші релевантні статті блогу (це передає вагу сторінок і затримує користувача).
